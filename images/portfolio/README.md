# Portofolio KBM Canopy

Unggah foto proyek asli pilihan ke folder ini melalui tombol **Add file → Upload files** di GitHub.

## Panduan
- Unggah foto JPG, JPEG, PNG, atau WebP.
- Gunakan nama file deskriptif, misalnya `kanopi-carport-depok-01.jpg`.
- Jangan unggah ratusan foto sekaligus; mulai dari 10–15 foto terbaik.
- Pilih foto yang memperlihatkan struktur rangka, kerapian pemasangan, dan hasil finishing.
- Jangan menghapus arsip asli di Google Drive.

Foto yang sudah diunggah akan ditinjau dan dioptimalkan sebelum dipasang pada halaman website.
